# CV Preferences

Personal preferences for CV generation. Edit this file to match your style.
Claude reads this before generating any version.

## Content Rules

- Don't list editors/IDEs in skills sections (e.g., VS Code, Neovim)
- Emphasize impact and results, not just responsibilities
- Keep descriptions concise — no fluff

## Tone

- Professional but approachable
- Focus on what was built/achieved
- Confident without being arrogant

## Structure Preferences

- 3-4 experience entries max
- Skills ordered by relevance to the offer
- Group similar roles when possible (e.g., freelance clients under one entry)
